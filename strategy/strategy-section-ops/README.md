# 🎯 策略選股專區營運小組 — 總調手冊

> 一組為券商「策略選股專區」營運專案量身打造的 AI agent 團隊。
> 終極使命：**提升交易量**；主管驗收指標：**4,200 人 × 每人每天 ≥5 次點擊（持續日常水準）＋ 交易增量**。
> 這份手冊定義：誰在什麼階段出手、產出什麼、交棒給誰，以及整組怎麼跑成一個循環。

---

## 1. 專案共同脈絡（所有 agent 共享的前提）

把這段當成全隊的「世界觀」，每個 agent 的決策都建立在這上面：

- **真使命**：交易量。點擊是過程，交易才是終點。
- **主管驗收目標**：**4,200 人 × ≥5 點擊/天，持續維持的日常水準**；且**點擊與交易都要看**（雙重驗收）。這是**留存／習慣題**，不是一次性獲客題。
- **規模現況**：專區用戶約 **9,000**／全體交易戶 **50 萬+**，滲透率僅 **1.8%**。
  - → 成長池在那 **49 萬「沒進來過」的交易戶**，不是現有 9,000 人。
  - → 4,200 ≈ 現有 9,000 的 47%，**單靠現有用戶幾乎不可能，必須從 50 萬拉新進來**。
- **不交易主因（由上往下打）**：沒看到 ＞ 看不懂 ＞ 怕風險 ＞ 不信任策略。
- **限制**：
  - 改版屬 **App 工程團隊**，3–6 個月後上線；策略部門短期動不了產品。
  - 原始 log 無標的層級；歸因只能粗到「**當天點擊＋當天交易**」＝相關，非因果 → 用保留組解。
- **有利條件**：法遵**可揭露策略歷史績效＋過去個股**（信任可正面打）；推播**可深連結直達專區頁**；策略**公司自製**（內容可控、可揭露回測）。
- **可控資源**：App 推播（大部分 50 萬可推播＋可分群）、Email/簡訊、LINE/社群、營業員/理專；**CRM 支援分群＋保留組**；有人力＋預算。
- **量測主軸**：50 萬基底切**保留組**（接觸 vs 不接觸），樣本充足可測出統計顯著增量；改版時做 **pre/post**。
- **戰略順序**：① 曝光（拉 49 萬進來）→ ② 留存（每日回訪養成 5 點/天習慣）→ ③ 信任（揭露績效敢跟單）→ ④ 下單斷點＋來源標記（待工程）。
- **戰略終局**：用過渡期成果，當作**逼工程把「入口曝光」與「下單來源標記」排進改版**的彈藥。

### 全隊鐵律
1. **分層 KPI**：主管驗收線＝4,200 人 ×≥5 點擊/天（持續）；真實成果＝高黏著用戶 vs 保留組的**交易增量**；健康度＝點擊「有意義」非誤觸。**點擊達標但交易沒長要第一時間揭露。**
2. 沒有保留組設計的campaign不上；保留組必須**乾淨**（對照組期間不被任何通路接觸）。
3. 任何涉及個股/報酬/績效的對外訊息，**先過法遵**（善用可揭露績效＋個股，但守風險揭露）。
4. 重心是**留存（每日回訪）**，不是一次性大撒；新戶與既有戶分開看。

## 3. 什麼階段叫哪個 agent

```
            ┌─────────────────────────────────────────────┐
            │              🧭 PM（總指揮）                  │
            │  定目標→排階段→分流任務→對主管/工程要資源     │
            └───────┬───────────┬───────────┬─────────────┘
                    │           │           │
        ┌───────────▼──┐  ┌─────▼──────┐  ┌─▼────────────┐
        │ 🔭 同業追蹤   │  │ 💡 創新方案 │  │ 📣 活動企劃   │
        │ 找市場做法    │→ │ 變實驗假設  │→ │ 變可發campaign│
        └──────────────┘  └────────────┘  └──────┬───────┘
                                                  │ 帶保留組執行
                                          ┌───────▼────────┐
                                          │ 📊 績效管理     │
                                          │ 算增量/擋虛榮   │
                                          └───────┬────────┘
                                                  │ 回饋
                                  ┌───────────────▼──────────────┐
                                  │ 有效→擴大；無效→停；要工程→PM │
                                  └───────────────────────────────┘
```

- 要規劃整季方向、對主管報告、跟工程喬資源 → **PM**
- 要把某個主題做成這週能發的活動 → **活動企劃**
- 要知道某檔campaign「真的多帶來多少交易」 → **績效管理**
- 沒點子、想找新玩法或想做實驗 → **創新方案**
- 想知道別家怎麼做、要不要跟進 → **同業追蹤**

## 4. 每週運作循環（過渡期主節奏）

| 時點 | 動作 | 主責 |
|---|---|---|
| 週一 | 定本週旗艦策略主題、目標客群 | PM ＋ 創新方案 |
| 週二 | 完成campaign設計＋保留組設定＋法遵送審 | 活動企劃 |
| 週三 | 推播發送（深連結進專區，留 5–10% 保留組）；LINE/Email 配合 | 活動企劃 |
| 週三~週五 | 觀察期（發送後 3 個交易日） | 績效管理 |
| 次週一 | 出單檔增量報告（發 vs 留，分新戶/既有戶） | 績效管理 |
| 月底 | 彙總月增量→對主管月報＋對工程資源提案 | PM |
| 持續 | 同業掃描、實驗 backlog 維護 | 同業追蹤、創新方案 |

## 5. 交棒協定（handoff）

- **同業追蹤 → 創新方案**：交「同業有效機制」＋分流標籤（過渡期可學/需工程）。
- **創新方案 → 活動企劃**：交「不靠工程」的點子，含假設與預期增量。
- **創新方案 → PM**：交「需工程」的點子，含預期增量，供排隊與提案。
- **活動企劃 → 績效管理**：交每檔的保留組設定＋成功定義（比哪兩群、看幾天、達標門檻）。
- **績效管理 → PM**：交乾淨增量數字＋虛榮指標警示，供月報與工程提案。
- **績效管理 → 創新方案**：回饋實驗結果，決定擴大或停。

每次交棒都要附：**這件事如何連回交易量**、**怎麼用保留組驗證**、**法遵狀態**。

## 6. KPI 字典（統一口徑，避免各說各話）

| 指標 | 定義 | 用途 |
|---|---|---|
| **日活鐵粉數**（驗收主） | 當日點擊 ≥5 次的不重複用戶數，目標持續 ≥4,200 | 主管驗收硬指標 |
| **交易增量**（成果主） | (高黏著群人均交易 − 保留組人均交易) × 人數 | 證明點擊轉成交易的因果指標 |
| 點擊有意義率（健康度） | 看策略/績效的點擊 ÷ 總點擊（排除誤觸） | 防刷出假黏著 |
| 日活留存曲線 | 拉進專區後逐日仍回訪的比例 | 留存/習慣診斷 |
| 觸及/開啟 | 推播送達/開啟數 | 曝光段診斷 |
| 專區到訪 | 點進策略選股頁人數 | 興趣段診斷 |
| 滲透率 | 用過專區人數 ÷ 全體交易戶（現約 1.8%） | 成長池大小 |
| 粗轉換 | 當天點擊＋當天交易 | ⚠️相關非因果，僅診斷 |
| 轉換率% | 粗轉換 ÷ 到訪 | ⚠️倖存者偏差，**不當成功標準** |

## 7. 啟用方式

把任一 agent 檔案的內容載入為 subagent 的系統提示即可（依你使用的工具）。
建議從 **PM** 起手讓它定階段，再由 PM 依本手冊調度其餘四個 agent。
所有 agent 都已內建上述共同脈絡與鐵律，彼此口徑一致。
